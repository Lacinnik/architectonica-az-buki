# Прототипы

Ранние интерфейсы и модули, не входящие в проверяемый runtime: React-компоненты (`.jsx`), модули ХРОНОС (`chronos_ai_module*.ts`), автономные HTML-страницы ГДЕЯ и словарь `bukovnik_70.json`. Файлы `живой_модуль_материализации_прототип_аз_буки*.jsx` — последовательные версии одного прототипа.

Проверяемые ядра остаются в корне репозитория: их копирует `Game-GDEYA`.

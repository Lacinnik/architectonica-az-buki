# Тексты корпуса

Исходные документы автора: манифесты, книга, атласы, лекции, протоколы и заметки (`.docx`, `.txt`, `.pdf`). Это источник истины; читаемые на GitHub Markdown-версии `.docx` лежат в [`../md/`](../md/README.md) и пересобираются командой `python3 tools/docx_to_md.py`.

`Опись` — ранний вариант описания репозитория.
